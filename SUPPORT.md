# Getting help

- **Something broken or a question about a port, a package or an app:** open an
  issue in the repository it concerns. If you are unsure which one, use
  [porthole](https://github.com/porthole-dev/porthole/issues).
- **A security problem:** follow [SECURITY.md](SECURITY.md), not a public issue.

These ports are unofficial. Please do not ask for help with them in
postmarketOS channels; they cannot support changes they did not make.
